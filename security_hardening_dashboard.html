Trust boundaries

  1. User → web server: treat requests, cookies, and uploaded content as untrusted.
  2. Web server → backend: validate input and enforce authorization on the server.
  3. Backend → database: use parameterized queries and narrowly scoped database permissions.
  4. Backend → external service: protect API keys and validate responses and webhook signatures.
